Tony Modpack

A Minecraft Java Edition modpack for Tony's community, featuring the mods and resource packs used during streams, alongside performance optimizations.

Overview

Tony Modpack brings together the gameplay modifications, visual enhancements, and performance tools used in Tony's Minecraft streams into one convenient package.

Features

- Mods: A collection of gameplay and quality-of-life modifications.
- Resource Packs: Visual enhancements and custom textures used in streams.
- Performance: Includes Fabulously Optimized for an improved gameplay experience.
- Shaders: Supports selected shader packs for enhanced visuals.
